Project Description:

This project analyzes sales, profit, quantity, customers, products, regions, markets, and shipping data using Power BI.

Objectives:

- Analyze Sales and Profit by category, region, market, and customer segment.
- Identify top-selling and loss-making products.
- Analyze monthly sales trends.
- Study the relationship between discount and profit.
- Analyze shipping modes, order priority, and state-wise sales.
- Identify top cities and high-performing sub-categories.

Tools Used:

- Power BI Desktop
- Power Query
- Power BI Visualizations
- Sales and customer dataset

Visualizations:

The dashboard uses bar charts, column charts, line charts, scatter charts, donut charts, maps, and stacked charts to present business insights.

Methodology:

The dataset was imported and cleaned using Power Query. Data types were verified, required visuals were created, filters were applied, and the dashboard was arranged to highlight key business insights.

Expected Outcome:

The dashboard helps identify profitable and loss-making products, sales trends, high-performing regions and categories, customer contributions, and shipping patterns.

Conclusion:

This project demonstrates how Power BI can transform sales data into meaningful visual insights and support data-driven business decisions.
